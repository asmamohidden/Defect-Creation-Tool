# Defect-Creation-Tool
This tool can be used by small business to create and track defects in Excel. This is introductory project
Frontend: HTML
Backend:Javascript

Double click to open the index.html download and use it you would not require any installation
To modify or customise based on your requirement open the index.html in any IDE

To update the fields in Excel open app.js in any IDE and modify it based on your preferance
